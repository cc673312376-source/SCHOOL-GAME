# 《挚友的1000种死法》

一款用城市空间关系触发事件的经营解谜游戏。目前仓库包含第一个可玩 Demo：“求学路漫漫”。

## 在线游玩

GitHub Pages 配置完成后，游戏地址为：

```text
https://你的用户名.github.io/仓库名/
```

也可以直接在电脑浏览器中打开 `index.html`，不需要安装依赖。

## 当前玩法

- 在 8×8 城市网格中规划学校与居民楼的位置。
- 学校初始坐标为 `(0,0)`，占地 3×3，影响区域 5×5。
- 居民楼初始坐标为 `(6,6)`，占地 2×2。
- 建筑距离采用直向 1、斜向 1.5 的边界最短距离。
- 距离达到 6 时触发“求学路漫漫”。
- 事件向学校 5×5 影响区写入犯罪值 +2，并令民生 -2。
- 将建筑重新放置，使距离低于 6，即可阻止事件。
- 首页“世界背景”介绍千禧年代老城区、星期日轮回、SAN 与觉醒值。

## 正式玩法方向

玩家是一名生活在千禧年代老城区的高中生。挚友死亡后，主角觉醒“星期日的轮回”，带着记忆回到惨剧发生前。周一至周五用于观察特殊事件、收集自然语言线索并调整城市；周六结算区域犯罪预值，决定最终案件是否发生。

游戏的核心不是案发后寻找凶手，而是推理建筑之间隐藏的距离、邻接与覆盖规则，把城市改造成让惨剧没有机会发生的样子。当前版本只验证第一条空间规则；五日流程、线索簿、SAN 3/3、派出所、大排档和小卖部等内容将逐步接入。

## 本地测试

安装 Node.js 后运行：

```bash
node tests/rules.test.js
```

测试覆盖初始事件、安全布局、5×5 热力写入，以及边相接和角相接距离。

## 共同维护

协作者请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。推荐通过功能分支和 Pull Request 修改；`main` 分支的每次更新都会先运行规则测试，再自动部署 GitHub Pages。

## 首次发布

1. 在 GitHub 创建仓库并推送本项目。
2. 打开仓库 `Settings → Pages`。
3. 将发布来源设为 `GitHub Actions`。
4. 打开 `Actions` 查看“Test and deploy game”。首次成功后即可获得公开网址。
