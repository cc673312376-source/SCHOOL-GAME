# 《挚友的1000种死法》

一款用城市空间关系触发事件的经营解谜游戏。目前仓库包含六建筑、固定道路、两次轮回与 SAN 3/3 的完整新手关原型。

## 在线游玩

[https://cc673312376-source.github.io/SCHOOL-GAME/](https://cc673312376-source.github.io/SCHOOL-GAME/)

也可以直接在电脑浏览器中打开 `index.html`，不需要安装依赖。

## 当前玩法

- 8×8 老城区包含 `xx中学`、`小卖部`、`派出所`、`大排档`、`居民楼1`、`居民楼2` 六栋建筑。
- 第4、5行是固定道路；建筑不能越界、重叠或占用道路。
- 第一次轮回只能观察，会依次触发“求学路漫漫”“无银光临”“杀熟”“醉酒斗殴”。
- 周六按建筑影响范围叠加犯罪预值。区域峰值达到 7 时触发最终案件“最初的误杀”。
- 第二次轮回解锁“乾坤挪移”和 SAN 3/3。每移动一栋建筑消耗 1 点 SAN。
- 新手关固定道路、两栋居民楼和派出所，只允许移动学校、小卖部与大排档。
- 建筑距离采用直向 1、斜向 1.5 的占地边界最短距离。

## 布局推算结果

程序穷举全部合法位置后得到：0、1、2 次移动均无安全解；恰好 3 次移动时有 30 种安全解。总位移最短的推荐顺序如下，坐标均指建筑左上角并使用玩家看到的 1—8 编号：

1. 小卖部：`(4,1) → (4,6)`
2. xx中学：`(1,1) → (4,1)`
3. 大排档：`(1,6) → (1,2)`

初始布局四项关键距离为 `5 / 5 / 1 / 6`，触发四起特殊事件，犯罪预值峰值为 `14`。推荐布局对应距离为 `3.5 / 1.5 / 5 / 4`，特殊事件归零，峰值降至 `2`，低于案件阈值 `7`。

## 正式玩法方向

玩家是一名生活在千禧年代老城区的高中生。挚友死亡后，主角觉醒“星期日的轮回”，带着记忆回到惨剧发生前。周一至周五用于观察特殊事件、收集自然语言线索并调整城市；周六结算区域犯罪预值，决定最终案件是否发生。

游戏的核心不是案发后寻找凶手，而是推理建筑之间隐藏的距离、邻接与覆盖规则，把城市改造成让惨剧没有机会发生的样子。当前版本已把五日事件压缩为一次“推进至周六”的规则验证；逐日演出、线索簿和更多城区仍待接入。

## 本地测试

安装 Node.js 后运行：

```bash
node tests/rules.test.js
node scripts/analyze-layout.js
```

规则测试覆盖六建筑初始事件、犯罪预值热力图、固定道路、推荐安全布局、30种三步解，以及边相接和角相接距离。分析脚本会输出初始值、各移动次数的解数量与推荐坐标。

## 共同维护

协作者请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。推荐通过功能分支和 Pull Request 修改；`main` 分支的每次更新都会先运行规则测试，再自动部署 GitHub Pages。

## 首次发布

1. 在 GitHub 创建仓库并推送本项目。
2. 打开仓库 `Settings → Pages`。
3. 将发布来源设为 `GitHub Actions`。
4. 打开 `Actions` 查看“Test and deploy game”。首次成功后即可获得公开网址。
